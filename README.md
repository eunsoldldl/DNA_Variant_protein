# DNA_Variant_protein
DNA 서열을 보고, 서열의 유전적 변이가 단백질의 구조적/기능적 변화로 이어지는 과정을 분석하는 프로그램을 (웹 형식으로 쓰기 쉽게) 를 만들어줘

# 분석 파이프라인
# 1. 염기 서열 분석
# 2. 변이 지점 식별
# 3. 물리 화학적 특성 분석(bio-python을 사용해 단백질의 분자량, 등전점, 불안정 지수, 지방족 지수, 친수성 지수 등을 계산)
# 4. 기능적 영향 예측(meta ai의 esm-2언어 모델을 사용해 치명적인 정도를 예측해줘)
-----------------------------------------------------------
우리는 gemini cli 바이브 코딩을 통해 다음 프로그램을 구현하려 했습니다.
<gemini cli를 통해 나온 결과물 복사 붙여넣기 > 🧪 추가 분석 결과 해석

   1. 침묵 변이 (Silent Mutation):
       * 현상: DNA 마지막 글자가 T에서 C로 바뀌었지만, 단백질은 똑같이 MAKF입니다.
       * 이유: TTT 코돈과 TTC 코돈은 둘 다 페닐알라닌(F)이라는 같은 아미노산을 지정하기 때문입니다.
       * 결과: 생명체에는 아무런 영향을 주지 않는 안전한 변이입니다.

   2. 겸상 적혈구 빈혈증 사례 (치명적 구조 변화):
       * 현상: 정상 헤모글로빈의 GAG 코돈이 GTG로 바뀌면서, 아미노산이 E(글루탐산, 산성-)에서 V(발린, 비극성)로 변했습니다.
       * 이유: 물을 좋아하는(친수성) '산성' 아미노산이 물을 싫어하는(소수성) '비극성' 아미노산으로 바뀌었습니다.
       * 결과: 단백질이 물속에서 둥글게 접히지 못하고 비극성 부분끼리 서로 달라붙으려고 합니다. 이로 인해 헤모글로빈들이 서로 엉겨 붙어 바늘 같은 섬유 구조를
         만들고, 결국 적혈구가 낫(Sickle) 모양으로 찌그러지게 됩니다. 

  이 시뮬레이션을 통해 "DNA 한 글자의 변화가 어떻게 치명적인 질병으로 이어지는지"를 화학적 성질 변화를 통해 명확히 확인할 수 있습니다._
